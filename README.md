# Fine-Tuning-Llama-3.2-Vision-for-Radiology-Image-Captioning-with-Evaluation-
Fine-tunes Llama 3.2 11B Vision on radiology images using LoRA (via Unsloth) to generate diagnostic-style captions, then evaluates the fine-tuned model against the base model using BLEU, ROUGE, METEOR, and BERTScore — with side-by-side comparison tables and plots.
